# Jacquet_Manuscript

PhD thesis manuscript of Pierre-Edouard Jacquet in quantum optomechanics and quantum optics.

This repository contains the complete LaTeX source of the manuscript, including:
- theoretical derivations,
- experimental methods,
- figures and data visualizations,
- appendices and supplementary calculations.

## Topics

- Quantum optomechanics
- Squeezed light
- Quantum noise and SQL
- Membrane-at-the-Edge (MATE) systems
- Continuous-variable quantum optics
- Frequency-dependent squeezing

## Structure

- `these/` — main manuscript sources
- `fig/`, `pictures/` — figures and illustrations
- `custom/`, `packages/` — custom thesis style and LaTeX packages
- `chap*/` — manuscript chapters

## Compilation

Compile using:

```bash
latexmk -pdf mythesis.tex
